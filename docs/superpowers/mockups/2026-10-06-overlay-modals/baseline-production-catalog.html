Quiet Tab — аудит оверлеев (канон, светлая тема)

Ниже — статические копии всех модалок и всплывающих поверхностей из newtab.js + design system (design-tokens.css, controls.css, surfaces.css, newtab.css). Размеры и отступы — из production CSS, без редизайна.

Итого 6 семейств, 15+ вариантов:

  • Desktop dialogs (4): add-link, edit-link, confirm-delete, edit-weather — .desktop-dialog + .desktop-backdrop
  • City modal (3 режима + error + suggestions overlay/docked + stacked): .city-modal
  • Add menu (2): корневое меню Add / подменю hidden metrics — .add-menu
  • City suggestions (2): overlay .weather-form__suggestions / docked --docked
  • Tooltip: #tooltip / .tooltip
  • Desktop status: #desktop-status — не modal, но плавающий alert-chip
